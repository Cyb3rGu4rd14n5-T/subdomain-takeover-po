🔓 Subdomain Takeover Vulnerabilities

🚨 Vulnerable: yoda.pharmeasy.in

Type: CloudFront + S3 Bucket Misconfiguration

Evidence:

1. CloudFront 404 Error:

$ curl -I https://yoda.pharmeasy.in
HTTP/1.1 404 Not Found
Server: CloudFront
X-Cache: Error from cloudfront

2. S3 Bucket Doesn't Exist:

$ curl yoda.pharmeasy.in.s3.amazonaws.com
<Error>
<Code>NoSuchBucket</Code>
<Message>The specified bucket does not exist</Message>

Attack Scenario:

  1. Attacker creates S3 bucket: yoda.pharmeasy.in
  2. Uploads phishing page to bucket
  3. CloudFront automatically serves attacker's content
  4. Users visit https://yoda.pharmeasy.in → See phishing page

Impact:

  • ✅ Phishing under trusted domain
  • ✅ Credential theft
  • ✅ Malware distribution
  • ✅ Brand reputation damage

📋 How to Reproduce:

# 1. Check current state
curl -I https://yoda.pharmeasy.in

# 2. Check S3 bucket
curl yoda.pharmeasy.in.s3.amazonaws.com

# 3. DNS points to CloudFront
nslookup yoda.pharmeasy.in

This is a security demonstration for responsible disclosure.
All findings have been reported to the appropriate security team.
